
# Hermes Agent 开发文档手册

## 1. 项目概述

**Hermes Agent** 是一个桌面端 AI 智能体框架，通过连接 DeepSeek Browser API 执行自动化任务。它采用类似 AutoGPT 的架构，支持自然语言驱动、并行工具调用、任务规划、记忆持久化和 Token 追踪等核心功能。

| 属性 | 值 |
|------|-----|
| 项目名称 | Hermes Agent |
| 编程语言 | Python 3.8+ |
| 核心依赖 | requests, PyQt6 (可选) |
| API 协议 | OpenAI 兼容 Chat Completion API |
| 许可证 | MIT |

## 3. 核心流程详解

### 3.1 Agent 执行循环

```
用户输入
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│ 1. 注入记忆到系统提示 (memory.auto_load_memory)             │
│    - 根据用户查询检索相关记忆                               │
│    - 加权排序：关键词(5) + 时效(3) + 重要度(2)             │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│ 2. LLM 推理 (client.chat)                                  │
│    - 传入系统提示 + 历史消息 + 工具 Schema                  │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│ 3. 判断响应类型                                             │
│    ├─ 无工具调用 → 返回最终答案，记录记忆                  │
│    └─ 有工具调用 → 进入执行阶段                            │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│ 4. 重复调用检测                                             │
│    - 连续 2 次相同工具调用 → 强制中断（防死循环）          │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│ 5. 工具执行                                                 │
│    ├─ 单个工具 → 直接执行                                   │
│    └─ 多个工具 → 并行执行 (ThreadPoolExecutor)             │
│    - 结果截断: 最长 50000 字符                             │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│ 6. 结果回写                                                 │
│    - 工具结果追加到历史消息                                 │
│    - 循环到步骤 2 (最多 max_rounds 轮)                     │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 任务规划与执行流程

```
用户目标
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│ 1. 任务拆解 (TaskPlanner.create_plan)                       │
│    - LLM 将目标拆解为带依赖关系的任务列表                  │
│    - 持久化到 hermes_tasks.json                            │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│ 2. 流水线执行 (Pipeline._run_loop)                          │
│    - 获取下一个依赖已满足的 pending 任务                   │
│    - 标记为 in_progress                                    │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│ 3. 任务执行 (Agent.chat)                                   │
│    - 使用 Agent 完成单个任务                               │
│    - 返回执行结果                                          │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│ 4. 任务验证 (Task.verify_completion)                        │
│    - 检查文件是否创建（写入类任务）                        │
│    - 检测失败信号关键词                                    │
└─────────────────────────────────────────────────────────────┘
    │
    ├─ 通过 → 标记 done
    │
    └─ 失败 → 标记 failed，连续失败计数 +1
                    │
                    ▼
         ┌─────────────────────────────────────┐
         │ 5. 自动重规划 (replan_threshold=2)  │
         │    - 连续失败 2 次触发重新拆解      │
         │    - 保留已完成任务                 │
         └─────────────────────────────────────┘
```

### 3.3 记忆系统流程

```
对话发生
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│ 1. 捕获 (record_turn)                                       │
│    - 过滤短内容 (< 4 字符)                                 │
│    - 智能截断 (≤ 2000 字符，在句子边界切断)              │
│    - 计算重要度 (1-10)                                     │
│    - 检测分类 (code/task/preference/knowledge)             │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│ 2. 入队 (写入内存队列)                                      │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│ 3. 后台落库 (_writer_loop)                                  │
│    - 每 2 秒批量写入 SQLite                                │
│    - 使用 MemoryDB.save_batch                              │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│ 4. 检索注入 (auto_load_memory)                              │
│    - 扩展查询词：原始词 + 同义词 + 拼音                    │
│    - 候选来源：关键词搜索 + 最近记忆 + 高重要度记忆        │
│    - 综合评分：关键词匹配 + 时效 + 重要度                  │
│    - 返回 Top 5 记忆，格式化为上下文                       │
└─────────────────────────────────────────────────────────────┘
```

## 5. API 客户端

### 5.1 端点

| 端点 | 方法 | 用途 |
|------|------|------|
| `/v1/chat/completions` | POST | 主要对话接口 |
| `/reset` | POST | 重置会话 |
| `/status` | GET | 服务状态检查 |
| `/login` | POST | 登录认证 |

### 5.2 请求格式

```python
payload = {
    "model": "deepseek-browser",
    "messages": [...],
    "tools": [...],           # 工具 Schema
    "session_id": "...",      # 会话标识
    "user": "hermes",         # Agent 身份
    "stream": False,          # 流式开关
    "new_conversation": False # 是否新建会话
}
```

### 5.3 响应解析

`ChatResult` 封装响应：

```python
class ChatResult:
    content: str = None          # 文本内容
    tool_calls: List[dict] = []  # 工具调用列表

    def has_tools() -> bool      # 是否有工具调用
```

流式响应中，`tool_calls` 逐步累积合并。

## 8. 错误处理与恢复

### 8.1 防死循环机制

- **重复调用检测**：连续 2 次相同工具调用 → 强制中断
- **最大轮数限制**：`max_rounds` 参数限制执行轮数
- **手动停止**：`request_stop()` 方法支持用户中断

### 8.2 工具执行保护

- **结果截断**：超过 50000 字符自动截断
- **JSON 解析容错**：`_parse_arguments` 处理多种格式
- **路径安全**：禁止单反斜杠（`\t` 被解析为制表符）

### 8.3 计划容错

- **断点续跑**：`resume()` 恢复失败任务
- **自动重规划**：连续失败触发重新拆解
- **依赖失效处理**：依赖失败的任务自动标记为 `skipped`

## 9. 扩展开发指南

### 9.1 添加新工具

```python
# 在 tools.py 中注册

def my_new_tool(args: dict) -> str:
    """工具实现"""
    param = args.get("param")
    # 逻辑处理
    return "执行结果"

register(
    name="my_tool",
    description="工具描述",
    parameters={
        "type": "object",
        "properties": {
            "param": {
                "type": "string",
                "description": "参数说明"
            }
        },
        "required": ["param"]
    },
    func=my_new_tool
)
```

### 9.2 添加新分类

在 `tool_index.py` 中更新分类映射：

```python
TOOL_CATEGORIES = {
    # ... 现有分类
    "我的新分类": ["tool1", "tool2"],
}
```

### 9.3 记忆系统扩展

- **添加同义词**：更新 `_SYNONYMS` 字典
- **调整分类关键词**：修改 `_CATEGORY_KEYWORDS`
- **自定义重要度**：修改 `_calc_importance()` 逻辑
